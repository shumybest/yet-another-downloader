# Support

Use [GitHub Issues](https://github.com/shumybest/yet-another-downloader/issues) for reproducible bugs and feature requests. Use [GitHub Discussions](https://github.com/shumybest/yet-another-downloader/discussions) for setup and usage questions when Discussions is enabled.

Before asking for help, run `pnpm verify`, review [docs/operation.md](docs/operation.md), and include:

- macOS version and CPU architecture;
- application version or commit;
- media type such as HLS, DASH, or direct MP4;
- task status and sanitized error text;
- whether a proxy is configured;
- the smallest reproducible steps.

Never post cookies, bearer tokens, signed query strings, private media URLs, downloaded private content, local history databases, or full logs containing those values. Replace hosts and identifiers with reserved examples such as `media.example.test`.

Security vulnerabilities must be reported privately through [SECURITY.md](SECURITY.md). The project cannot provide help bypassing DRM, authentication, paywalls, access controls, rate limits, or copyright restrictions.
