# yet another downloader v0.1.3

This Intel macOS pre-release improves local-engine startup diagnostics and recovery.

## Included

- Startup progress shows service checks, Python preparation, process launch, settings/history recovery, yt-dlp loading, and API validation, with elapsed time and attempts.
- Slow health checks are treated as pending instead of incorrectly reporting a port conflict. Complete Content-Length responses no longer wait for socket closure.
- Actual port conflicts identify the listening process and PID. The app never terminates another project's server.
- Background retry/restart preserves failure details, waits for the old managed engine to release its port, and refreshes the desktop API session.
- Early sidecar exit is reported, and both development and packaged builds write engine output to `~/Library/Logs/m3u8-bridge/engine.log`.
- The Chrome extension, pinned Python/yt-dlp engine, FFmpeg/ffprobe runtime, license notices, corresponding source, and checksums are included.

## Installation

Download the DMG or ZIP and verify it with `SHA256SUMS.txt`. The app is ad-hoc signed but not Apple-notarized; macOS may require opening it through Finder's context menu.

Existing data, settings, port `8765`, and the `m3u8bridge://` integration remain compatible. If another service is listening on port 8765, close that service or move it to another port, then use the app's retry button. Inspect listeners with `lsof -nP -iTCP:8765 -sTCP:LISTEN`.

## Platform

- macOS Intel `x86_64` only. Apple Silicon is not validated in this release.
- No Apple Developer ID signature or notarization.

## Limitations

- A normal webpage URL is not a direct media URL. Use the Chrome extension when the source requires browser cookies or special request headers.
- Protected or DRM-encrypted streams are not supported. Downloads remain subject to source-site authorization and terms.
