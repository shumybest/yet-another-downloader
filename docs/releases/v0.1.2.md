# yet another downloader v0.1.2

This Intel macOS pre-release adds manual download creation to the desktop app.

## Included

- Create a task by pasting an HLS (`.m3u8`), DASH (`.mpd`), or direct-video media URL into the desktop app.
- Specify HLS, DASH, or direct video when a valid media URL has no recognizable extension.
- Optionally name the task; existing output directory, proxy, and concurrency settings apply.
- Invalid URLs show an inline explanation. Failed submissions retain the form values and show technical error details.
- The bundled Chrome extension, local Python/yt-dlp engine, FFmpeg runtime, license notices, corresponding source, and checksums remain included.

## Installation

Download the DMG or ZIP and verify it with `SHA256SUMS.txt`. The app is ad-hoc signed but not Apple-notarized; macOS may require opening it through Finder's context menu.

## Platform

- macOS Intel `x86_64` only. Apple Silicon is not validated in this release.

## Licensing

Original project code is GPL-3.0-or-later. Bundled third-party components retain their own licenses. The matching corresponding-source archive and dependency manifests are release assets.

## Limitations

- No Apple Developer ID signature or notarization.
- A normal webpage URL is not a direct media URL. Use the Chrome extension when the source requires browser cookies or special request headers.
- Protected or DRM-encrypted streams are not supported. Downloads remain subject to source-site authorization and terms.
