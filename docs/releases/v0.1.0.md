# yet another downloader v0.1.0

This is the first public Intel macOS pre-release of `yet another downloader`.

## Included

- Tauri desktop download manager.
- Local Python and yt-dlp engine sidecar.
- Bundled GPL-enabled FFmpeg and ffprobe runtime with non-system dependencies.
- Embedded Chrome Manifest V3 capture extension and installation guide.
- Dependency manifests, license notices, exact Homebrew build metadata, corresponding source, and SHA-256 checksums.

## Installation

Download the DMG or ZIP asset. The application is ad-hoc signed but not Apple-notarized. macOS may require opening it through Finder's context menu or removing quarantine after verifying `SHA256SUMS.txt`:

```sh
xattr -dr com.apple.quarantine "/Applications/yet another downloader.app"
```

## Platform

- macOS Intel `x86_64` only.
- Apple Silicon is not validated in this release.

Original project code is GPL-3.0-or-later. Bundled third-party components retain their own licenses. The matching corresponding-source archive and dependency manifests are release assets. See `THIRD_PARTY_NOTICES.md` inside the application or source repository.

## Limitations

- No Apple Developer ID signature or notarization.
- Protected or DRM-encrypted streams are not supported.
- Downloads remain subject to the source site's authorization and terms.
