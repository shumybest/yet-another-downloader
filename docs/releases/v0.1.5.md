# yet another downloader v0.1.5

Intel macOS pre-release improving post-download processing and proxy reliability.

- Processing stages show real FFmpeg progress, processed media time, speed and elapsed time. Unknown-duration stages use an indeterminate bar instead of stale download percentages.
- Advancing transcodes, remuxes and validation scans are no longer stopped by a fixed 900-second total limit. A 180-second no-advancement guard and cancellation remain enabled. Repeated unchanged progress records do not mask a stall.
- Compatible video codecs are remuxed without unnecessary video re-encoding. AV1 and other incompatible codecs use H.264/AAC with the faster veryfast preset; output files may be larger at comparable quality.
- Post-processing failures preserve the downloaded task directory and report its location. These files are unvalidated; retry still downloads from the source and deleting history does not remove retained files.
- Retry callbacks support yt-dlp's zero-based `n` keyword as well as the internal one-based positional attempt, with bounded backoff.
- HLS downloads use the configured HTTP/SOCKS proxy only for upstream requests, not the local relay. Empty proxy settings explicitly disable inherited proxy environment variables.
- Successful polling and HLS access logs are quiet; failures and task operations remain logged.

## Upgrade

Quit the old App from its menu-bar menu before replacing it. Prepare the bundled extension through Help, reload it in Chrome, and refresh video pages. Existing settings, history, port 8765 and deep links remain compatible.

## Platform And Verification

The App includes Python/yt-dlp, FFmpeg/ffprobe and the Chrome extension. Intel x86_64 only, ad-hoc signed, not Apple-notarized. Matching GPL corresponding source and SHA-256 checksums accompany the binaries.

Regression coverage includes real FFmpeg progress during processing, active processing beyond a shortened legacy deadline, unchanged-progress stalls, retained downloads after processing failure, yt-dlp RetryManager callback compatibility, proxy HLS download and complete short-fixture decode. Full-length signed-site downloads and native Quick Look are not established by these tests.
