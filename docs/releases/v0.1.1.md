# yet another downloader v0.1.1

This Intel macOS pre-release improves desktop background operation and repairs the public CI workflow.

## Included

- Closing the main window keeps active downloads and the local engine running.
- The macOS menu bar shows aggregate live download speed while tasks are active.
- Left-clicking the menu bar icon restores the main window; the right-click menu provides status, restore, and explicit quit actions.
- The desktop app automatically reconnects menu bar status after an engine restart.
- GitHub Actions now has an explicit Node.js type dependency and uses an available macOS runner for Rust/Tauri checks.
- The bundled Chrome extension, local Python/yt-dlp engine, GPL-enabled FFmpeg runtime, license notices, corresponding source, and checksums remain included.

## Installation

Download the DMG or ZIP asset. The application is ad-hoc signed but not Apple-notarized. After verifying `SHA256SUMS.txt`, macOS may require opening it through Finder's context menu or removing quarantine:

```sh
xattr -dr com.apple.quarantine "/Applications/yet another downloader.app"
```

## Platform

- macOS Intel `x86_64` only.
- Apple Silicon is not validated in this release.
