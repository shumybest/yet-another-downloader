- shipping the applicable license and copyright notices;
- publishing the exact FFmpeg build configuration;

- satisfying the licenses of every bundled dynamic library;
- avoiding claims that every third-party component is covered solely by the project's GPL license.

The GPLv3 text used by verified local builds is included at [licenses/FFMPEG-GPL-3.0.txt](licenses/FFMPEG-GPL-3.0.txt). This file alone does not complete the corresponding-source obligation. Each binary release must also include a matching corresponding-source archive, exact build configuration, Homebrew formulae and receipts, dependency manifests, and checksums generated by the release tooling.

Binary releases are produced manually until signing, notarization, and multi-architecture automation are available. Generated FFmpeg binaries remain ignored by Git and are never part of the source repository.
